Como hospedar no GitHub Pages e acessar pelo celular

Sim! Você pode colocar este código no GitHub e acessá-lo de qualquer celular, tablet ou computador de forma gratuita e rápida através do GitHub Pages.

1 Crie um repositório no GitHub

Acesse github.com, crie um novo repositório (pode ser público ou privado).

2 Salve o arquivo como index.html

Envie este código exato para o repositório com o nome exato de index.html na branch principal (main ou master).

3 Ative o GitHub Pages

No seu repositório, vá em Settings > Pages. Em "Build and deployment", selecione a branch main (ou root) e clique em Save.

4 Acesse pelo celular!

O GitHub gerará um link (ex: https://seu-usuario.github.io/seu-repositorio/). Basta abrir esse link no navegador do celular, colar seus textos gigantes e depois abrir no PC!
